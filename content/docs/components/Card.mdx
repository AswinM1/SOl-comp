# Card

<div className="max-w-3xl min-h-[400px]  flex max-h-2xl p-4 justify-center mx-0  items-center bg-neutral-900 rounded-md">
<Card/>
</div>
A square, glassy card whose background is an animated warm gradient clipped into a shifting wave shape, topped with a soft radial glow and a title block — evoking a desert dune or sunset scene.

## Features

- **Animated wave background** — `clipPath` is animated across three polygon keyframes, making the gradient's visible shape ripple like a dune line or wave, looping forever.
- **Warm gradient fill** — a `red → orange → yellow` vertical gradient sits behind the animated clip, giving the wave a sunset/desert palette.
- **Soft glow overlay** — a radial gradient positioned at the top-left adds a glassy highlight over the whole card.
- **Layered content** — a label and title (`"Deserts"` / `"Sahara"`) sit in a `relative z-10` layer above the animated background and glow.
- **Self-contained animation** — no external state; the wave is driven entirely by Framer Motion's `animate`/`transition` props.

## Component

```tsx
"use client"

import { motion } from "motion/react"

interface CardProps {
  /** Small label above the title, e.g. category. */
  label: string

  /** Main title text. */
  title: string

  /** Tailwind gradient "from" color class. */
  fromColor?: string

  /** Tailwind gradient "via" color class. */
  viaColor?: string

  /** Tailwind gradient "to" color class. */
  toColor?: string

  /** Full wave animation cycle duration, in seconds. */
  duration?: number

  /** Card width/height in Tailwind size units. */
  size?: number
}

function Card({
  label,
  title="Deserts",
  fromColor = "from-red-600",
  viaColor = "via-orange-400",
  toColor = "to-yellow-600",
  duration = 7,
  size = 52,
}: CardProps) {
  return (
    <div className="mx-auto mt-10 flex items-center justify-center">
      <div
        style={{
          width: `${size * 0.25}rem`,
          height: `${size * 0.25}rem`,
        }}
        className="
          relative
          overflow-hidden
          rounded-[28px]
          border
          border-neutral-400
          bg-neutral-300
          shadow-2xl
        "
      >
        {/* Animated wave */}
        <motion.div
          animate={{
            clipPath: [
              "polygon(0 50%, 35% 55%, 30% 65%, 45% 55%, 60% 65%, 75% 55%, 100% 60%, 100% 100%, 0 100%)",

              "polygon(0 80%, 15% 65%, 30% 55%, 45% 65%, 60% 55%, 75% 65%, 100% 55%, 100% 100%, 0 100%)",

              "polygon(0 80%, 15% 55%, 30% 65%, 45% 55%, 60% 65%, 75% 55%, 100% 60%, 100% 100%, 0 100%)",
            ],
          }}
          transition={{
            duration,
            repeat: Infinity,
          }}
          className={`
            absolute
            inset-0
            bg-linear-to-t
            ${fromColor}
            ${viaColor}
            ${toColor}
          `}
        />

        {/* Soft glow */}
        <div
          className="
            absolute
            inset-0
            bg-[radial-gradient(circle_at_top_left,rgba(255,255,255,0.4),transparent_45%)]
          "
        />

        {/* Content */}
        <div className="relative z-10 flex h-full flex-col justify-between p-6">
          <div>
            <p className="text-sm font-medium tracking-tight text-neutral-700">
              {label}
            </p>

            <h1 className="mt-2 font-serif text-3xl leading-none tracking-tight text-neutral-700">
              {title}
            </h1>
          </div>
        </div>
      </div>
    </div>
  )
}

export default Card
```

## Props

```tsx
interface CardProps {
  /** Small label above the title, e.g. category. Default: "Deserts". */
  label: string;
  /** Main title text. Default: "Sahara". */
  title: string;
  /** Tailwind gradient "from" color class. Default: "from-red-600". */
  fromColor?: string;
  /** Tailwind gradient "via" color class. Default: "via-orange-400". */
  viaColor?: string;
  /** Tailwind gradient "to" color class. Default: "to-yellow-600". */
  toColor?: string;
  /** Full wave animation cycle duration, in seconds. Default: 7. */
  duration?: number;
  /** Card width/height in Tailwind size units. Default: 52 (13rem). */
  size?: number;
}
```

| Prop | Type | Default | Description |
|---|---|---|---|
| `label` | `string` | `"Deserts"` | Small caption text shown above the title. |
| `title` | `string` | `"Sahara"` | Large serif heading text. |
| `fromColor` | `string` | `"from-red-600"` | Gradient start color (bottom, since the gradient direction is `to-t`). |
| `viaColor` | `string` | `"via-orange-400"` | Gradient midpoint color. |
| `toColor` | `string` | `"to-yellow-600"` | Gradient end color (top). |
| `duration` | `number` | `7` | Seconds for one full loop through the three `clipPath` keyframes. |
| `size` | `number` | `52` | Card width and height, in Tailwind spacing units (`w-52 h-52` = 13rem / 208px). |

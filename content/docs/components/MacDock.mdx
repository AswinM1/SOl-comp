# MacDock
<div className="max-w-3xl min-h-[400px]  flex max-h-2xl p-4 justify-center mx-0  items-center bg-neutral-900 rounded-md">
<MacDock/>
</div>

A row of pill-shaped icons that grow smoothly as the cursor moves closer to them and shrink back as it moves away — the classic macOS Dock magnification effect — driven by continuous `MotionValue` transforms rather than per-item React state.

## Features

- **Distance-based magnification** — each item's size is derived from its live pixel distance to the cursor, so the closest item is largest and items further away taper back to their resting size.
- **Smooth spring sizing** — the raw distance-to-size mapping is passed through `useSpring`, so items grow/shrink with natural, slightly bouncy motion instead of snapping.
- **Single shared cursor value** — one `mouseX` motion value lives in the parent and is passed down to every `DockItem`, avoiding a re-render of the whole dock on every mouse move.
- **Configurable geometry** — item count, resting size, magnified size, and gap are all controlled via props.
- **Graceful reset on mouse leave** — moving the cursor away from the dock sends `mouseX` far off-screen, so every item smoothly relaxes back to its resting size.
- **Layered inset/outset shadows** — both the dock container and each item use a combined inset + drop shadow for a glassy, tactile look.

## Installation

This component depends on `motion` (the successor package to `framer-motion`) and Tailwind CSS for styling.

```bash
npm install motion
```

Make sure Tailwind CSS is configured in your project, then copy the component below into your codebase, e.g. `components/mac-dock.tsx`.

## Usage

```tsx
import MacDock from "@/components/mac-dock";

export default function Page() {
  return (
    <MacDock
      items={["Finder", "Mail", "Safari", "Music", "Notes"]}
      itemSize={48}
      magnifiedSize={84}
      gap={12}
    />
  );
}
```

## Component

```tsx
"use client";

import { useRef } from "react";
import {
  motion,
  useMotionValue,
  useSpring,
  useTransform,
  type MotionValue,
} from "motion/react";

interface MacDockProps {
  items?: string[];
  itemSize?: number;
  magnifiedSize?: number;
  gap?: number;
}

interface DockItemProps {
  label: string;
  index: number;
  mouseX: MotionValue<number>;
  containerRef: React.RefObject<HTMLDivElement | null>;
  itemSize: number;
  magnifiedSize: number;
}

function DockItem({
  label,
  index,
  mouseX,
  containerRef,
  itemSize,
  magnifiedSize,
}: DockItemProps) {
  const distance = useTransform(mouseX, (value: number) => {
    const element = containerRef.current?.children[index];
    const bounds = element?.getBoundingClientRect();

    if (!bounds) return 0;

    return value - bounds.left - bounds.width / 2;
  });

  const size = useTransform(
    distance,
    [-150, 0, 150],
    [itemSize, magnifiedSize, itemSize]
  );

  const width = useSpring(size, {
    mass: 0.1,
    stiffness: 150,
    damping: 12,
  });

  const height = useSpring(size, {
    mass: 0.1,
    stiffness: 150,
    damping: 12,
  });

  return (
    <motion.div
      style={{
        width,
        height,
        background:
          "linear-gradient(to bottom, rgba(29, 208, 253, 1) 50%, rgba(25, 25, 255, 1) 100%)",
      }}
      className="
        flex
        items-center
        justify-center
        rounded-full
        text-white
        [box-shadow:inset_0_2px_4px_rgba(0,0,0,0.4),0_2px_5px_rgba(255,255,255,0.2)]
      "
    >
      {label}
    </motion.div>
  );
}

function MacDock({
  items = ["Hello"],
  itemSize = 50,
  magnifiedSize = 80,
  gap = 16,
}: MacDockProps) {
  const containerRef = useRef<HTMLDivElement>(null);
  const mouseX = useMotionValue<number>(-1000);

  const handleMouseMove = (
    event: React.MouseEvent<HTMLDivElement>
  ): void => {
    mouseX.set(event.clientX);
  };

  const handleMouseLeave = (): void => {
    mouseX.set(-10000);
  };

  return (
    <div className="mt-10 flex w-full items-center justify-center">
      <div
        ref={containerRef}
        onMouseMove={handleMouseMove}
        onMouseLeave={handleMouseLeave}
        style={{
          gap,
        }}
        className="
          flex
          items-end
          rounded-3xl
          bg-neutral-300
          px-6
          py-4
          [box-shadow:inset_0_2px_4px_rgba(0,0,0,0.4),0_2px_5px_rgba(255,255,255,0.2)]
        "
      >
        {items.map((item, index) => (
          <DockItem
            key={`${item}-${index}`}
            label={item}
            index={index}
            mouseX={mouseX}
            containerRef={containerRef}
            itemSize={itemSize}
            magnifiedSize={magnifiedSize}
          />
        ))}
      </div>
    </div>
  );
}

export default MacDock;
```

## Props

### `MacDock`

| Prop | Type | Default | Description |
|---|---|---|---|
| `items` | `string[]` | `["Hello"]` | Labels rendered as dock items, left to right. |
| `itemSize` | `number` | `50` | Resting size (width & height, in px) of each item when the cursor is far away. |
| `magnifiedSize` | `number` | `80` | Maximum size (in px) an item reaches when the cursor is directly over its center. |
| `gap` | `number` | `16` | Horizontal spacing (in px) between items, applied via the container's `gap` style. |

### `DockItem` (internal)

`DockItem` isn't exported on its own — it's rendered by `MacDock` for each entry in `items` — but understanding its props clarifies how the magnification is wired up.

| Prop | Type | Description |
|---|---|---|
| `label` | `string` | Text rendered inside the item. |
| `index` | `number` | The item's position in the dock, used to look up its own DOM node via `containerRef.current.children[index]`. |
| `mouseX` | `MotionValue<number>` | The shared cursor X position, read (not subscribed to via React state) to compute distance. |
| `containerRef` | `React.RefObject<HTMLDivElement \| null>` | Ref to the dock's container, used to measure each item's live bounding box. |
| `itemSize` | `number` | Passed through from `MacDock`; the item's resting size. |
| `magnifiedSize` | `number` | Passed through from `MacDock`; the item's peak size. |

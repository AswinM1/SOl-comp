# Installation

Sol Components is built on top of the [shadcn/ui](https://ui.shadcn.com/) registry format, so you can install components directly into your project using the shadcn CLI.
or you can copy paste the components into your project and modify it directly.


## Requirements

Sol components use **[Motion](https://motion.dev)** for animations and **[Tailwind CSS](https://tailwindcss.com/)** for styling.
Make sure both are configured in your project before installing components. you can check out official docs of tailwind css to configure tailwind for your projects

## Quick Start

Make sure your project has Tailwind CSS configured and motion is installed in your project, then run:

```bash
npx shadcn@latest add https://sol-components.vercel.app/r/shimmer.json
```
or any other components you like to add them to your projects.s

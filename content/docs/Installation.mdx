# Installation

Sol Components is built on top of the [shadcn/ui](https://ui.shadcn.com/) registry format, so you can install components directly into your project using the shadcn CLI.

## Dependencies

## Requirements

Sol components use **[Motion](https://motion.dev)** for animations and **[Tailwind CSS](https://tailwindcss.com/)** for styling.

Make sure both are configured in your project before installing components.

### Motion

Sol uses [Motion](https://motion.dev) for animations.

Install it with:

```bash
npm install motion
```

## Quick Start

Make sure your project has Tailwind CSS configured, then run:

```bash
npx shadcn@latest add https://sol-components.vercel.app/r/shimmer.json
```

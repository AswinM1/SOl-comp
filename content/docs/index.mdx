# Introduction

Sol components is a open source component library with 10+ components which you can easily copy paste into your projects. This also supports download using shadcn cli commands

## Why to use SOL components ?
Most of the component libraries out there have the same components styled differently . But this contains cool components which can be used in your projects to improve user experience. These components are unique and some are inspired from other great engineers out there
